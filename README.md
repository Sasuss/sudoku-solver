# Sudoku Solver

A python script that solves sudoku for you.<br>
**The script is still being worked on, this is not the final version**

## Used Libraries
Numpy - *All of the sudokus are stored in ndarray for better manipulation* <br>
Math - *Used for mor complex operations needed for sudokus that arent 9x9*

## AI Usage
Most of the AI usage comes from Gemini generating me sudokus that i can test the script on, the rest of AI usage is documented using code comments.
